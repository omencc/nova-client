Nova Client

A modern Minecraft utility client focused on speed, visuals, and customization.



✦ Overview

Nova Client is a lightweight and visually polished Minecraft client designed for players who want advanced movement, combat enhancements, rendering tools, and deep UI customization in one package.

Built with performance in mind, Nova combines clean visuals with responsive modules and modern animations.

✦ Installation

1. Install Minecraft Forge/Fabric
2. Place Nova Client into mods folder
3. Launch Minecraft
4. Open GUI with Right Shift
