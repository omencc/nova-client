## 🌌 Modern Minecraft Utility Client

**Nova Client** is a lightweight Minecraft utility client focused on **performance, visuals, and customization**.

Built with smooth rendering, modern UI design, and responsive modules, Nova delivers a polished experience while keeping gameplay fluid and FPS high.

Designed for players who want advanced combat, movement, rendering, and utility systems in one clean package.

# 📥 Installation

1. Install **Minecraft Forge** or **Fabric**
2. Open your `.minecraft` folder
3. Place Nova Client inside the `mods` folder
4. Launch Minecraft
5. Open the GUI using `Right Shift`
